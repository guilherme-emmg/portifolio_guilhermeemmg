# Portfólio Profissional — Guilherme Emanuel

Portfólio profissional de **Guilherme Emanuel Martins Moreira Gonçalves**, com foco em **Quality Assurance (QA)**, **Testes de API** e **Análise de Dados**.

---

## 🚀 Como Executar no Navegador (Sem Node.js / Sem npm)

Este projeto foi desenvolvido em arquitetura web pura e independente (**HTML5**, **CSS3** e **JavaScript Vanilla**).

1. **Execução Direta (Mais simples):**
   - Basta dar um **duplo clique** no arquivo `index.html` ou abri-lo com qualquer navegador (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
   - Não é necessário ter o Node.js instalado no computador.
   - Não é necessário rodar `npm install` nem `npm run dev`.

2. **Com VS Code (Live Server - Opcional):**
   - Caso utilize o Visual Studio Code, você pode clicar com o botão direito em `index.html` e selecionar **"Open with Live Server"**.

3. **Publicação no GitHub Pages:**
   - Este repositório está 100% pronto para publicação direta no **GitHub Pages**, bastando habilitá-lo na aba *Settings > Pages* do seu repositório no GitHub.

---

## 📁 Estrutura de Arquivos

- `index.html`: Estrutura semântica completa de todas as 8 seções do portfólio, com fontes do Google, Tailwind CSS via CDN e ícones em SVG puro (leves e offline).
- `style.css`: Estilos de tipografia, transições e acessibilidade.
- `script.js`: Toda a lógica de interatividade (menu mobile, filtro dinâmico de projetos, modal de ficha técnica e cópia de e-mail).
